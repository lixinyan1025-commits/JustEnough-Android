# 刚刚好 Android v1.4.7

“刚刚好”是一款仅面向竖屏 Android 手机的本地生活规划 App。支持 Android 10–16（minSdk 29、targetSdk 36），不依赖 Google 服务；HarmonyOS NEXT、平板、横屏与折叠屏展开布局不在范围内。

图文版产品介绍（含 16 张真机截图与 2 段演示视频）见 [产品介绍.md](./产品介绍.md)，演示素材在 [demo/](./demo) 与 [screenshots/](./screenshots)。

## 当前功能

- 底栏：计划 → 今天 → AI分析 → 设置，默认进入“今天”。
- 四象限计划与计划安排：计划库固定为四区，每区独立滚动并支持长按排序、跨区移动；安排继续使用明确的起止时间，支持一个时段放入多个可选计划。
- 今天页：只负责执行已经排好的全天计划，顶部显示五格充实度与溢出，并提供晚间复盘。
- 执行：确认后计时并打开绑定应用；支持暂停、继续、延长、“够了”、完成和放弃。只有“够了”与“完成”填写充实度，且一次执行只结算一次。
- 一个透明可滚动的“桌面计划”组件：顶部充实度，下面只列从早到晚的全部计划；空心圆表示未完成，对号表示已完成，进行中任务可直接进入完成页。
- 每项计划可绑定一个应用；时间安排可用数字直接输入并通过5/15分钟、整点和常用时长快捷调整。提前30分钟、5分钟提醒，到点后像闹钟一样循环响铃，并可按安排自动开始任务；默认需要用户点“进入任务”才打开绑定应用，也可在单个安排里开启自动打开。打开后显示“现在开始：任务 / 目标”短时说明浮层。
- AI分析：DeepSeek 官方只提供 V4 Flash 与 V4 Pro；自定义 OpenAI 兼容接口仍可填写地址与模型，并保留备用 DeepSeek、持久连接状态、聊天和结构化逐项提案。
- 原创动态桌宠“小满”：以确认造型重绘成单一 Lottie 分层矢量人物，不打包精灵大图；会结合系统时间、当天安排和执行状态主动显示气泡，适时用选项询问难度、疲劳、轻松程度和心情，并提供约72%宽、35%高的透明桌面聊天小窗。
- 铃声支持内置清脆音、系统闹钟音、系统通知音、本机音频或静音；最长响铃时间可选30秒、1分钟、2分钟、5分钟或直到手动关闭，并支持音量渐强和独立振动。任务开始、完成、“够了”、放弃等都有清脆且克制的反馈音。
- “今天”页顶部显示准确日期、秒级时间和下一个任务倒计时；计划与“今天”都支持5分钟至数小时后的“稍后开始”，到点自动开始并响铃，重启和修改时间后仍会恢复。
- 每个时间安排可分别控制到点自动开始、自动打开绑定应用、铃声和振动。应用跟随手机系统时间和时区，改时间、切时区及重启后自动重建提醒。
- Android Keystore 保存 API Key；AES-GCM 加密本地备份不包含密钥。
- 小米、华为、荣耀、OPPO/一加/真我、vivo/iQOO、三星和原生 Android 的自动识别、手动切换说明与四项诊断。

## 安装

安装 [release/JustEnough-v1.4.7-release.apk](release/JustEnough-v1.4.7-release.apk)，使用与 v1.4.0 相同的正式证书签名，可从 v1.4.0 至 v1.4.6 直接覆盖升级，不会丢失计划、安排、执行历史、充实度、绑定应用、AI记录和小满设置。升级后需要先为尚未分类的旧计划完成一次四象限分类。

v1.4.6 修复：小满悬浮聊天窗点击输入框可唤起系统输入法并直接发送消息；键盘弹出时聊天窗自动上移到键盘上方；修复 Android 12+ 透明悬浮窗“点击输入框穿透”问题（输入框改为不透明底）。

v1.4.7 修复：浮窗输入框改为单行，键盘上的“发送”键可直接发送（此前多行输入会让回车变成换行，导致看起来发不出去）；发送后立即清空输入框，并在接口失败时在聊天流中显示“没发出去：原因”，避免无反馈。浮窗聊天与 App 内「AI 分析」共用同一 AI 调用链路，回复会直接显示在浮窗中。

1. 开启通知和闹钟提醒，并运行“测试提醒”。
2. 添加“桌面计划”组件，并在桌面保留足够网格空间；旧版重复组件需要在系统桌面长按移除。
3. 如需 AI，在“AI接口”中同意数据范围、填写新生成的密钥并点“保存并测试”。聊天中公开过的密钥必须先撤销。
4. API 测试成功后可按需开启小满，并授权“显示在其他应用上层”。

系统不允许普通 App 自动创建独立桌面页；请在系统桌面长按空白处添加组件。厂商桌面的后台与自启动权限请按设置页识别出的品牌说明调整。
